# Aswin's Portfolio

A modern, responsive portfolio website built with vanilla HTML, CSS, and JavaScript. Features a dark theme with neon gradients, smooth animations, and multiple sections showcasing skills, education, and projects.

## 🎨 Features

- **Modern Design**: Dark theme with cyan and purple neon gradients
- **Responsive Layout**: Fully responsive design that works on all devices
- **Smooth Animations**: Scroll animations, hover effects, and transitions
- **Interactive Elements**: Smooth scrolling, active navigation states, and contact form
- **Multiple Sections**:
  - Hero Section with profile image and stats
  - About Me with personal information
  - Education timeline
  - Skills with progress bars
  - Learning Journey
  - Projects showcase
  - Career Aspirations with roadmap
  - Contact section with map

## 📁 Project Structure

```
portfolio-1/
├── index.html       # Main HTML file
├── styles.css       # CSS styles
├── script.js        # JavaScript functionality
└── README.md        # This file
```

## 🚀 Getting Started

### Prerequisites
- A modern web browser
- Optional: A local development server

### Installation

1. Clone the repository:
```bash
git clone <repository-url>
cd portfolio-1
```

2. Open in your browser:
```bash
# Simple way - just open the HTML file
open index.html

# Or use a local server (Python)
python -m http.server 8000
# Then visit http://localhost:8000
```

## 🎨 Customization

### Colors
Edit the CSS variables in `styles.css`:
```css
:root {
    --primary: #00d4ff;      /* Cyan */
    --secondary: #7c3aed;    /* Purple */
    --dark-bg: #0a0e27;      /* Dark background */
    /* ... more variables */
}
```

### Content
Update personal information in `index.html`:
- Name, title, description
- Education details
- Skills and proficiency
- Projects
- Contact information

### Images
Replace the profile image in the hero section:
```html
<img src="your-image.jpg" alt="Your Name">
```

## 📱 Responsive Breakpoints

- **Desktop**: Full layout (1024px and above)
- **Tablet**: Adjusted grid layouts (768px to 1023px)
- **Mobile**: Single column layout (below 768px)

## 🔧 Development

### Adding New Sections

1. Add HTML structure in `index.html`
2. Add CSS styling in `styles.css`
3. Add any JavaScript functionality in `script.js`

### Performance Tips

- Images are lazy-loaded by default
- CSS animations use GPU acceleration (transform, opacity)
- Smooth scrolling behavior is hardware-accelerated
